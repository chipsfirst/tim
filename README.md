# Т.И.М. — техническая иммерсивная модель

Настольный компаньон: CRT-монитор на подставке в углу экрана, зелёные пиксельные глаза,
бип-бипы, быстрые кнопки и вопросы к Алисе через встроенный браузер.

## Запуск из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install pywebview
.venv/bin/python main.py
```

## Сборка

- macOS: `./build_mac.sh` → `dist/ТИМ.app`
- Windows: `build_windows.bat` → `dist\ТИМ.exe`

## Управление

- наведение на монитор — открыть поле ввода;
- Enter — спросить Алису, ↑/↓ — история вопросов;
- «Погода» — прогноз без Алисы (Open-Meteo), «Время», «Шутка» — мгновенно;
- ⌗ — открыть окно Алисы для входа в аккаунт;
- ⏻ на панели монитора — выход, значок динамика — выключить звук.

## Что учесть

Ответы Алисы читаются со страницы, поэтому отвечают с задержкой и зависят от вёрстки
alice.yandex.ru. Для вопросов нужен вход в аккаунт через ⌗.
