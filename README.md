# Т.И.М. — техническая иммерсивная модель

Настольный компаньон: CRT-монитор на подставке в углу экрана. Зелёные пиксельные глаза,
бип-бипы, рожицы, RPG-показатели, меню на экране, тетрис и вопросы к Алисе через
встроенный браузер. Работает на macOS и Windows.

## Запуск из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install pywebview pyobjc-framework-Quartz   # macOS
.venv/bin/python main.py
```

## Сборка

- macOS: `./build_mac.sh` → `dist/TIM.app`
- Windows: `build_windows.bat` → `dist/TIM.exe`
- релизы (DMG и установщик) собирает GitHub Actions по тегу `v*`

## Управление

- наведение на монитор — открыть поле ввода;
- клавиши под корпусом: питание, меню, сон, звук, разворот (расширенный режим);
- `≡` — меню: покормить, танец, погода, шутка, «Игры ▸» (тетрис, крестики-нолики, понг, бегунок), «Сервис ▸» (заряд, время, состояние, настройки, напоминания, автозапуск, диагностика, обновления, сброс);
- кнопка с полумесяцем — погасить экран, останется мигающий курсор;
- кнопка разворота — расширенный режим с полем ввода и широким пузырём;
- ⏻ — выход, динамик — звук;
- ⌥Space (на Windows Alt+Space) — вернуть фокус в поле ввода;
- Enter — спросить Алису, ↑/↓ — история вопросов.

## Показатели

`⚡ батарея`, `♥ здоровье`, `☾ сон` под экраном. Батарея садится со временем, здоровье
падает при низком заряде и недосыпе, сон восстанавливается, когда робот спит. Кормление
и «Заряд» поправляют состояние, точные проценты — в пункте меню «Состояние».

## Структура

```
main.py            запуск, окно, цикл, мост к странице
platform_impl.py   выбор платформенной реализации
mac_backend.py     экран, курсор, трей, хоткей, автозапуск (macOS)
win_backend.py     то же для Windows + перетаскивание в своём потоке
ui/index.html      разметка (без скриптов и стилей внутри)
ui/style.css       оформление корпуса и панелей
ui/css/*.css       стили меню и тетриса
ui/js/config.js    настройки и их чтение
ui/js/audio.js     синтез звука, флоппи, модем, мелодии
ui/js/talk.js      цитаты, шутки, мотивирующие фразы
ui/js/alice.js     вопрос к Алисе, таймаут, история
ui/js/faces.js     жесты и рожицы
ui/js/stats.js     показатели RPG
ui/js/menu.js      реестр действий и меню
ui/js/tetris.js    тетрис
ui/js/games.js     крестики-нолики, понг, бегунок
ui/app.js          ядро: окно, панель, быстрые ответы, загрузка
ui/config.json     тайминги и размеры в одном месте
tests/             дымовые проверки
```

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют зоны попадания курсора, полноту платформенного интерфейса, отсутствие
«поймал и забыл», состав меню и конфиг. В CI то же самое плюс `node --check` по всем
JS-файлам и автопроверка меню при запуске (`menu audit` в логе).

## Голос

Голосовые функции убраны: распознавание речи системным движком роняло
неподписанный бандл. Запись и озвучка удалены, разрешения из Info.plist сняты.

## Логи

`~/Library/Logs/TIM.log` на macOS, `%TEMP%\TIM.log` на Windows. Уровни `info/warn/error`,
ротация на мегабайте, ошибки из страницы тоже пишутся туда.

## Что учесть

Ответы Алисы читаются со страницы, поэтому отвечают с задержкой и зависят от вёрстки
alice.yandex.ru. Для вопросов нужен вход в аккаунт через ⌗. На macOS для ⌥Space нужно
разрешение «Универсальный доступ» — после каждой пересборки его надо выдавать заново.
